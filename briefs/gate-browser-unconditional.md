# Part (b): the browser leg runs whenever CI would, and asks the right diff

Cut at the post-floors window per #3092's serial rule (one gate.sh
delivery at a time; the floors file is R165). The DIRECTION was ruled
at #3017 on slate's argument and is not reopened here: a skip
predicate must be exhaustive to be safe, `PERCH_PATHS` has recorded
its own gap once (#2518 §2), CI does not attempt exhaustiveness, and
the louder-statement alternatives are dead against one measured red
main. One claimable item (#2589). Properties, not code (#2574).

## The three clauses

1. **The browser leg runs whenever CI would run it** — which, per
   `ci.yml`, is always. The perch-paths skip predicate retires. The
   report still names the leg's condition (ran, with its instrument
   parameters, per R155's five-parameter clause), and the ~4-minute
   cost per gate is the price already accepted knowingly at #3092.
2. **Any owed-ness or scope question the battery still asks is asked
   of the MERGE-BASE diff** — what did this branch touch — never the
   symmetric two-point diff (#3090, folded binding at #3092): a green
   from a leg exercising code the merge will discard is not
   over-measurement, it is measurement of nothing, and slate's
   four-file demonstration is the exhibit. If clause 1 removes the
   last consumer of the predicate, this clause governs its removal
   (delete it or fix it — do not leave a wrong predicate idle in the
   file).
3. **`report()` names the harness that produced it** — one line, so
   two reports from different harnesses are distinguishable WITH M
   UNCHANGED (#3201, folded at #3202). The count-assertion
   alternative is refused for slate's two-case reason: it is
   redundant where M moves and fails a correct gate where it does
   not. This closes the working-directory dependence #3200's
   near-miss exposed — the dual-harness procedure's only
   discriminator today exists solely when a delivery changes M.
