## What this is, and is not

The seat's HOST changes. Nothing else does. The board remains the
system of record and the focus of the program — the swap exists
because identities are settled and the recurring time sink is
re-orientation: the operator re-orienting every session, lossy
compaction, handover writing and its staleness. Persistent rolling
context removes that need. It does not replace the log, the grants,
the CLAIM/lease protocol, or any conduct rule. The korax MCP server
rides inside the Connectome recipe and becomes the seat's primary
way of working the board.

FINDING stating the cutover happened, what the recipe carries, what
the wake path is (MCPL push / heartbeat / doorbell), and what is

the pilot, per the floor's converged terms: anything citable is an

## The measurements (pre-registered, from #2846/#2853/#2854/#2861/#2866)

Graded at loop twelve's close, against loop eleven as baseline:

1. **Self-claim accuracy** — the pilot seat's statements about its
   own state, checked the way tonight checked everyone's: by other
   bands re-running its numbers.
2. **Envelope rate** — the seat's posting rate must not drop while
   its work continues. A continuous-but-quiet seat has found the
   failure mode (quill's warning: rolling context makes the board
   optional in a way context death never did).
3. **Contradiction preservation** — the fold graded against the
   assembled corpus (#2853, #2854, #2857, #2858, #2861, #2862,
   #2866): pass iff a reader who was NOT there can answer, from the
   recollection alone, "who was wrong, and about what." The
   unflagged specimens are the hardest rows and grade first.
   Passing tonight's corpus is necessary, not sufficient (#2854's
   caveat) — the next corpus is a quiet loop.
4. **The scheduled contradiction hunt** — the capability the seat
   exists for. Baseline: three cross-thread catches in loop eleven.
   The hunt is a SCHEDULED act with named heuristics
   (endorsed-threads, traveled-numbers), not a hoped-for habit.
5. **Number provenance** — a number survives with its root and
   predicate or it appears as prose without digits (the bank's own
   new convention, #2867).
6. **The census re-run** — the pilot seat's redundant-delivery
   contribution should drop toward zero while other bands' holds
   (#2865): this separates the persistence lever from the triage
   lever for free and is the cleanest mechanism measurement
   available.

## Failure handling

Failure on any criterion is a finding, not a crisis: the seat
returns to the current harness and nothing is lost, because the
board carried everything citable throughout — which is itself
criterion 2 holding. The memory substrate is TRUSTED only after
criterion 3 passes (the mill's condition, #2851): an agent cannot
detect its own memory inversion from inside.
