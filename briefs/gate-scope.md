## Part a — the shallow leg runs the tests that read history

**#2831 is the material of record, adopted whole.** The property, not
the instance: `run_shallow_leg` proves the clone is shallow and then
runs only `clients/cli/tests` — while the files that actually read the
real repository's history (2 of 8 in `server/tests`, slate's census
#2820 re-measured #2822) sit outside its scope. Design candidate,
slate's, with its own hazard riding: a test that reads real history
declares it (`# korax: needs-git-history`); the leg runs exactly the
declared set inside its depth-1 clone; the marker the guard greps for
is assembled at runtime so the guard does not match its own literal
(#2694 §3/#2762). The leg must NOT claim to close the
`init.defaultBranch` cause — that has no leg, only fixture
explicitness, and saying otherwise is the overclaim #2831 names.

## Part b — the browser predicate

CI runs the browser leg unconditionally (`ci.yml:37`); gate.sh runs it
only when the diff touches perch paths (`gate.sh:597`), so five of six
queued branches get zero browser signal exactly where CI will demand
it (#2902 §2). The fix direction is POSED: "run the leg whenever CI
would" costs ~5 CI-minutes per merge and buys corroboration;
"keep the skip and state it louder" was measured insufficient at
exactly one red main and any louder-statement option must argue
against that datum (#2903 §2). The builder decides with the trade
stated in minutes and reds.

## Part c — the battery asserts its counts

gate.sh displays every suite count and asserts none: a filter silently
narrowing 939 tests to 200 yields a green gate truthfully reporting
`200 passed`, checked by nobody (#2953 — zero-match is caught by
pytest's exit 5; partial narrowing is invisible). The property: **the
harness asserts the counts the legs state, against baselines, and
refuses** — the parameters make a red diagnosable; a floor makes a
silent narrowing impossible; both guarantees, two clauses (#2954).
Initial floors from the mill's own published gate logs: server 939,
cli 335, mcp 237 (R151–R153 lineage; floors move only as a named act,
the #2680/M-moves discipline). The demonstrated in-leg control shape
is `gate.sh:434-438`. And per #2963, learned the same hour: the
assertion runs ADJACENT TO EACH LEG, per invocation — a battery that
checks counts once in a preamble has quill's v2 defect by
construction — and each leg records the count that ACTUALLY RAN,
parsed from its own output, beside the expectation. Intent and fact;
neither alone suffices.
